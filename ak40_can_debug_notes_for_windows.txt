  3. CAN 하드웨어 배선
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Teensy 4.1 CAN1:
    CTX (TX) = Pin 22 (GPIO_AD_B1_08, ALT2 = FLEXCAN1_TX)
    CRX (RX) = Pin 23 (GPIO_AD_B1_09, ALT2 = FLEXCAN1_RX)

  CAN 트랜시버: SN65HVD230 (3.3V)
    Teensy Pin 22 → SN65HVD230 D (Tx)
    Teensy Pin 23 → SN65HVD230 R (Rx)
    SN65HVD230 CAN_H → 모터 CAN_H
    SN65HVD230 CAN_L → 모터 CAN_L
    종단저항: 트랜시버 내장 + R-Link 내장 → CAN_H-L 사이 60Ω 확인 (멀티미터)
    → 별도 종단저항 불필요, 배선 문제 아님 (멀티미터로 전부 검증 완료)

  AK40-10 모터 측:
    CAN 커넥터: 4핀 단자 (CAN IN: LHHL, CAN OUT: LHHL)
    테스트 시 연결:
      모터 CAN IN → SN65HVD230 트랜시버 (Teensy)
      모터 CAN OUT → R-Link (+ R-Link에 UART선도 연결, 안하면 CubeMars 프로그램에서 인식 불가)
    USB-C 포트 → R-Link을 통한 UART 연결

  6. 프로토콜 레퍼런스 (펌웨어에 구현된 것들)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A) VESC Servo Mode (Extended CAN Frame)
  ----------------------------------------
  CAN ID = (packet_type << 8) | motor_id

  명령:
    SET_DUTY     = 0   → duty × 100000 (int32, big-endian)
    SET_CURRENT  = 1   → current_mA (int32, big-endian)
    SET_BRAKE    = 2   → brake_current_mA (int32, big-endian)
    SET_RPM      = 3   → ERPM (int32, big-endian)
    SET_POS      = 4   → position

  응답 (모터→호스트, 자동 송출):
    STATUS (type=9):    ERPM(int32) + Current(int16/10) + Duty(int16/1000)
    STATUS_4 (type=16): Tfet + Tmotor + Iin + PidPos
    STATUS_5 (type=27): Tachometer + Vin

  B) MIT Mode (Standard CAN Frame, 8 byte)
  ------------------------------------------
  Enter motor mode: ID=motor_id, data = FF FF FF FF FF FF FF FC
  Exit motor mode:  ID=motor_id, data = FF FF FF FF FF FF FF FD
  Zero position:    ID=motor_id, data = FF FF FF FF FF FF FF FE

  MIT control frame:
    Byte 0-1: position (16-bit, -12.5~12.5 rad)
    Byte 2-3: velocity (12-bit, -65~65 rad/s)
    Byte 4:   Kp (12-bit, 0~500)
    Byte 5-6: Kd (12-bit, 0~5)
    Byte 7:   torque (12-bit, -18~18 N·m)

  C) 기타 CubeMars 프로토콜 (추정, 미확인)
  ------------------------------------------
  comm_type << 24 | motor_id (Extended)
  comm_type 0 = get_info
  comm_type 1 = current loop
  comm_type 6 = set CAN ID (?)
  comm_type 7 = read params

  8. GM4108 모터 측정 파라미터 (참고, wrist 조인트)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  이 파라미터들은 wrist 짐벌 모터(GM4108H)에 대한 것으로,
  AK40-10과는 별개이지만 DOB 구현 시 함께 사용됨.

  Motor 1 (wrist_pitch):
    Phase R = 5.5 Ω (멀티미터 실측)
    L = 0.34 mH (스텝 응답)
    Kt = 0.154 N·m/A (연속 ramp + 선형회귀, 2026-05-15 측정)
    Pole pairs = 11

  Motor 2 (wrist_roll):
    Phase R = 5.5 Ω
    L = 0.38 mH
    Kt = 0.138 N·m/A
    Pole pairs = 11

  전류센서: 션트 10mΩ, gain 50 (INA181A2)
  엔코더: AS5048A SPI (14-bit, 16384 counts/rev)
  SimpleFOC gain 반전 필요: gain_a *= -1; gain_b *= -1;
